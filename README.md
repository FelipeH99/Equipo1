# Equipo1 · Práctica de Git y HTML

Ejercicio de colaboración mediante Git. El repositorio contiene `Archivo.html`, una página con textos utilizada para practicar cambios y trabajo en equipo.

## Ver el ejercicio

Cloná el repositorio y abrí `Archivo.html` en un navegador. No requiere dependencias, compilación ni backend.

## Alcance

Material de aprendizaje; no es una aplicación ni un proyecto de producto. Mis proyectos principales y experiencia actual están en [mi portfolio](https://felipeheredia.vercel.app).
